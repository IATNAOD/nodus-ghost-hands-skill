# Ghost Hands

Управление Windows-компьютером голосом через ассистента NODUS.

«Запусти доту», «закрой игру», «сделай громче на компьютере», «выключи компьютер через полчаса», «найди в интернете рецепт борща».

Ghost Hands состоит из двух частей:

- **навык NODUS** `ghost_hands` — понимает команды, узнаёт говорящего по голосу и решает, какому компьютеру их отдать;
- **приложение Ghost Hands для Windows** — выполняет команды на компьютере: запускает и закрывает программы и игры Steam, Epic Games, GOG и меню «Пуск», меняет громкость, выключает компьютер.

Можно подключить несколько компьютеров: у каждого своё имя для голоса («игровой», «ноутбук»).

## Установка

### 1. Навык в NODUS

1. Скачайте `ghost_hands-<версия>.zip` из [последнего релиза](https://github.com/IATNAOD/nodus-ghost-hands-skill/releases/latest).
2. В панели NODUS под учётной записью администратора откройте «Навыки» → «Установленные» → «Установить из файла» и выберите ZIP.
3. Включите навык переключателем.

Навык открывает в домашней сети порт **47300**: к нему подключаются компьютеры. Порт меняется в «Настройках устройства» навыка.

### 2. Ключ

Откройте в панели NODUS «Навыки» → Ghost Hands → вкладку **«Мои настройки»**. Там ваш личный ключ вида `GH-XXXX-XXXX-XXXX-XXXX-XXXX-XXXX`.

У каждого члена семьи свой ключ. Компьютеры, подключённые по ключу, принадлежат его владельцу, и NODUS отличает их по голосу владельца.

### 3. Приложение на компьютере

1. Скачайте `GhostHands-Setup-<версия>.exe` из [последнего релиза](https://github.com/IATNAOD/nodus-ghost-hands-skill/releases/latest).
2. Запустите установщик. Права администратора не нужны.

   Пока приложение не подписано, Windows SmartScreen предупредит о неизвестном издателе: нажмите «Подробнее» → «Выполнить в любом случае».
3. Вставьте ключ, придумайте имя компьютера для голоса и нажмите «Подключить».

   Удобнее кнопкой «Открыть в приложении» в «Моих настройках»: она сама подставит ключ.

Приложение запускается вместе с Windows, живёт в трее и обновляется само.

Цвет значка в трее:

| Значок | Состояние |
|---|---|
| оранжевый | подключено |
| фиолетовый | подключается |
| серый | нет связи |
| с красной точкой | нужно внимание |

## Что можно сказать

| Что | Примеры |
|---|---|
| Запуск | «запусти доту», «открой стим», «давай поиграем в майнкрафт», «запусти хром на ноутбуке» |
| Закрытие | «закрой доту», «закрой игру», «закрой активное окно», «выйди из телеграма» |
| Громкость | «сделай громче на компьютере», «громкость на компьютере тридцать», «выключи звук на ноутбуке» |
| Музыка и видео | «пауза на компьютере», «продолжи на компьютере», «следующий трек на компьютере» |
| Питание | «выключи компьютер», «перезагрузи ноутбук через полчаса», «выключи компьютер в 23:00», «отмени выключение», «заблокируй компьютер», «выключи монитор» |
| Поиск | «найди в интернете рецепт борща», «загугли погоду в Сочи», «найди на ютубе обзор» |
| Включение | «включи компьютер» (Wake-on-LAN) |
| Статус | «какие компьютеры в сети», «что запущено на компьютере» |
| Родительский контроль | «сними ограничения на детском компьютере на час», «верни ограничения на детском компьютере», «сбрось лимиты на детском компьютере» |

Громкость и музыку NODUS отдаёт компьютеру, только если в фразе есть «на компьютере» или его имя. Иначе «громче» и «пауза» относятся к колонке NODUS.

Полный список фраз — в [docs/voice-commands.md](docs/voice-commands.md).

### Названия программ

NODUS сравнивает русское произношение с английскими названиями: «ведьмак три» → The Witcher 3, «контра» → Counter-Strike 2, «хром» → Google Chrome.

Если название произносится необычно, добавьте голосовое название в приложении: «Приложения и игры» → «+ голосовое название». Проверить, как NODUS поймёт фразу, можно там же, в «Проверить фразу».

Когда NODUS не уверен, он переспросит: «Запустить Dota 2?» или «Что именно: A или B?». С какого процента совпадения запускать без вопроса, задаёт настройка навыка. Процент для конкретной фразы показывает «Проверить фразу». Если включён ИИ, незнакомое название подберёт модель. После вашего «да» NODUS запомнит это название.

## Несколько компьютеров

- Нет компьютеров в сети — NODUS так и скажет.
- В сети один ваш компьютер — команда уходит ему.
- Компьютер назван («на ноутбуке», «на игровом») — команда уходит ему.
- В сети несколько, имя не названо:
  - если команду может выполнить только один компьютер (например, игра установлена только на одном), NODUS выполнит её без вопроса;
  - если вы обращались к компьютеру меньше двух минут назад, NODUS выберет его снова;
  - иначе NODUS спросит: «Какой компьютер: игровой или ноутбук?».

**Общий компьютер семьи** (переключатель в приложении) доступен всем пользователям NODUS, а не только владельцу ключа.

## Настройки навыка

Вкладка «Настройки устройства» навыка видна администратору NODUS.

| Настройка | По умолчанию |
|---|---|
| Порт для компьютеров | 47300 |
| Голос не узнан | спросить «Кто это?» |
| Подтверждать личность голосом | нет |
| Дети | всё, кроме выключения и перезагрузки |
| Гости могут пользоваться общими компьютерами | нет |
| Всегда спрашивать, какой компьютер | нет |
| Совпадение названия, при котором запускать без уточнения | 86 % |
| Подбирать незнакомые названия с помощью ИИ | да |
| Сколько ждать ответа компьютера | 8 с |

В приложении на компьютере, на вкладке «Команды», можно выключить отдельные возможности и включить подтверждение выключения голосом. Там же выбирается поисковик и шаг громкости.

## Wake-on-LAN

«Включи компьютер» будит выключенный компьютер, если:

- компьютер подключён к роутеру кабелем (по Wi-Fi пробуждение обычно не работает);
- Wake-on-LAN включён в BIOS и в свойствах сетевой карты Windows;
- «Быстрый запуск» Windows выключен;
- приложение хотя бы раз подключалось к NODUS: так навык узнаёт MAC-адрес.

Если сказать «запусти доту», когда компьютер выключен, NODUS предложит его включить и запустит игру после загрузки.

## Родительский контроль

Ограничивает время за компьютером и в играх. Включается для отдельного компьютера в «Моих настройках» навыка: переключатель «Родительский контроль» в карточке компьютера. Настраивать контроль может только владелец компьютера — тот, чьим ключом он привязан. Пока контроль выключен, его настройки не видны.

**Подготовка компьютера ребёнка:**

1. Привяжите компьютер своим ключом, а не ключом ребёнка: владелец компьютера может снять ограничения.
2. Оставьте ребёнку обычную учётную запись Windows, без прав администратора.
3. Включите контроль и задайте PIN (6–12 цифр, без повторов и цифр подряд).

**Что настраивается:**

- лимиты на компьютер и на игры, отдельно на будни и на выходные (субботу и воскресенье); пустое поле — без лимита;
- продление кнопкой на самом компьютере: на сколько минут (по умолчанию 15) и сколько раз в день (по умолчанию 2), отдельно для компьютера и игр;
- на сколько PIN и голос снимают ограничения (по умолчанию 2 часа);
- что считается игрой: игры Steam, Epic и GOG отмечены сами, к ним можно добавить любые приложения компьютера или убрать лишние.

**Что происходит на компьютере:**

- Время компьютера идёт, пока сеанс Windows разблокирован и ребёнок им пользуется; простой дольше 5 минут не считается (фильм на весь экран и игра — считаются). Время игр идёт, пока запущена игра.
- За 10 минут до конца лимита в углу экрана появляется предупреждение с кнопкой «+15 мин».
- Время игр вышло — игры закрываются (как по «×», через 30 с принудительно) и не запускаются до завтра. Остальным можно пользоваться.
- Время компьютера вышло — компьютер не выключается: поверх всех мониторов открывается экран «Время за компьютером на сегодня закончилось». Музыка и видео встают на паузу, новые программы закрываются.
- Новый день начинается в полночь по часам компьютера. Без связи с NODUS ограничения действуют по последним правилам.

**Как снять ограничения:**

| Как | Кто |
|---|---|
| Кнопки «Снять на 1/2/4 ч» и «до конца дня» в «Моих настройках», «Вернуть ограничения», «Сбросить время за сегодня» | только владелец компьютера, в своём аккаунте |
| Голосом: «сними ограничения на детском компьютере на час», «разреши ещё поиграть на детском компьютере», «верни ограничения на детском компьютере», «сбрось лимиты на детском компьютере» | только владелец компьютера: NODUS узнаёт его по голосу. Возраст не важен — старший брат-владелец может помочь младшему |
| «Я родитель» и PIN на экране компьютера | любой, кто знает PIN |

**Защита приложения.** Под контролем приложение Ghost Hands нельзя закрыть из трея, поставить на паузу, отвязать, а его настройки доступны только для чтения. Оно запускается вместе с Windows. Если приложение всё же закрыли через Диспетчер задач, оно запустится снова, а владельцу придёт уведомление. Уведомления также приходят, когда PIN несколько раз ввели неверно, когда ограничения сняли PIN и когда компьютер пропал из сети, не выключившись.

**Ограничения:**

- Клавиатура не перехватывается: кнопка Win и меню «Пуск» могут на мгновение появиться поверх экрана блокировки, запущенное оттуда закроется в течение пары секунд. Ctrl+Alt+Del и Диспетчер задач не блокируются.
- Ребёнок с правами администратора Windows может обойти защиту. Владелец узнает об этом по уведомлению.
- Игры в браузере считаются временем компьютера, а не игр.

## Сценарии NODUS

В сценариях доступны:

- **события:**
  - «Компьютер в сети»;
  - «Компьютер выключился»;
  - «Запущено приложение»;
  - «Закрыто приложение»;
  - «Родительский контроль: время закончилось», «время продлили кнопкой», «Ghost Hands закрыли, компьютер пропал или ввели PIN» — только для владельца компьютера;
- **блоки:**
  - запустить приложение;
  - выключить или перезагрузить;
  - громкость;
  - сообщение на экране;
  - «Компьютер в сети?»;
  - включить по сети.

## Безопасность

- Приложение и навык общаются внутри домашней сети без шифрования, по личному ключу. Не подключайте компьютер к NODUS через общественный Wi-Fi.
- NODUS может запустить только те программы, которые включены в приложении. Пути и адреса по сети не передаются.
- Если ключ мог попасть к чужим, нажмите «Перевыпустить» в «Моих настройках»: все ваши компьютеры отключатся до ввода нового ключа.
- «Пауза управления» в приложении временно запрещает NODUS что-либо делать на компьютере.

## Если не работает

| Что видно | Что сделать |
|---|---|
| «NODUS не найден в сети» | Компьютер и NODUS должны быть в одной сети. Укажите IP-адрес NODUS в «Адрес NODUS» на экране подключения. |
| «NODUS не отвечает» | Проверьте, что навык включён, и порт: в PowerShell `Test-NetConnection project-nod.local -Port 47300`. |
| Не подключается по Wi-Fi | Отключите в роутере «изоляцию клиентов» или гостевую сеть. Профиль сети Windows должен быть «Частная». |
| «Ключ не подходит» | Ключ перевыпустили: скопируйте новый из «Моих настроек». |
| Громкость и закрытие программ не работают | Антивирус мог заблокировать `GhostHelper.exe` из папки приложения: добавьте его в исключения. |
| Нужны журналы | «Настройки» → «Открыть папку журналов». |

## Для разработчиков

| Путь | Что там |
|---|---|
| `skill/` | навык: Node 22, CommonJS, без сборки |
| `client/` | Electron 44, React, TypeScript; `client/helper/` — C#-помощник `GhostHelper.exe` |
| `docs/protocol.md` | протокол между навыком и приложением |
| `docs/nodus-skills-guide.md` | руководство по навыкам NODUS |
| `CLAUDE.md` | правила и команды проекта |

```sh
yarn && npm --prefix client install   # корень — yarn (yarn.lock), клиент — npm (client/package-lock.json)
npm test                    # тесты навыка
npm run dev-host            # навык без устройства NODUS: сервер для ПК, мини-панель :8080, консоль фраз
npm --prefix client run helper   # собрать GhostHelper.exe (нужен .NET SDK)
npm --prefix client run dev      # приложение в режиме разработки
npm --prefix client test         # тесты приложения
```

Навык и приложение выпускаются вместе, с одной версией:

```sh
npm run release              # 1.0.0 → 1.0.1
npm run release -- minor     # 1.0.0 → 1.1.0; также major или точная версия 2.0.0
npm run release -- --dry-run # только показать план
```

Скрипт работает из чистой ветки `main`:

1. прогоняет тесты навыка и приложения;
2. записывает версию в `package.json` и `skill/skill.json`;
3. коммитит `Release vX.Y.Z` и пушит тег `vX.Y.Z`.

Тег запускает сборку на GitHub. В релиз попадают установщик приложения и ZIP навыка. Релиз помечается Latest, и установленные приложения обновляются из него.

Если навык в NODUS старее приложения, приложение покажет это на экране «Статус».
